# cpp-learning

## О проекте
Учебный проект для изучения С++.

Программа предназначена для ведения списка, который может хранить элементы разных типов данных.

Что было изучено в ходе написания проекта:
- возвращаемые значения и `dangling references`
- const как контракт
- контейнер STL `std::vector`
- алгоритмы STL
- итераторы (на практическом уровне)
- RAII (включая ресурс — файл)
- разделение интерфейса и реализации
- модель шаблонов на базовом уровне

## Сборка и запуск
Убедитесь, что у вас установлен один из компиляторов С++: 
- gcc
- clang
- или другой...

И запустите поочередно команды:
```shell

clang++ -c main.cpp -o main.o
clang++ main.o -o main
./main
```

Если у вас не `clang`, замените `clang++` на тот компилятор, который у вас установлен на компьютере.
## Использование

При запуске приложение появляется контекстное меню, в котором можно выбрать с помощью цифр действие с данными.

Все результаты добавления и удаления записываются локально (данные программы сохраняется).
